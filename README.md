# Colombian Aerospace Agency – Website

## Live Demo
[View the website](https://hanpal16-ux.github.io/colombian-aerospace-agency/)

## Project Description
Colombian Aerospace Agency is a multi-page website for a fictional
national space agency in Colombia. It presents the agency's mission,
its history, an online shop with aviation and astronomy products, a
contact page with a form, and a terms and privacy page.

This was my first web project, developed for the Introductory
Frontend – HTML & CSS course of the Full Stack Software Development
program at Canadian Business College (CBC).

Note: the agency, its history, and its contact information are
fictional and were created only for this project.

## Technologies
- HTML5
- CSS3 (Flexbox and media queries)

## How to Run
**Option 1:** Visit the live demo link above.

**Option 2:** Run it on your computer:
1. Clone the repository:
```bash
   git clone https://github.com/hanpal16-ux/colombian-aerospace-agency.git
```
2. Open the project folder.
3. Open `index.html` in your web browser.

## Features
- Six connected pages: Home, Mission, History, Shop, Contact, and
  Terms and Privacy
- Navigation bar with a clickable logo that returns to the home page
- Shop page with six products, prices, and buttons with hover effects
- Contact page with the agency's information and a contact form
- Responsive design that adapts the layout for mobile phones
- SEO meta tags (description and keywords) on every page
- Consistent header and footer across all pages
